# Omalingo

Mobile-first interactive prototype based on the Omalingo Figma Main Flow.

## Client demo

Recommended walkthrough:

1. Complete language and goal setup.
2. Pass the short listening check.
3. Create the hero.
4. Start Mission 01 from the feed.
5. Use **Type instead** when the browser has no microphone permission.
6. Finish the mission, then open Journey and Profile.

Prototype scope: Main Flow only. Concepts, Case Study, and Logo pages are not included yet.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://127.0.0.1:5173`.

## Production build

```bash
pnpm build
pnpm preview
```

The prototype includes onboarding, hero setup, feed, four learning levels with 20 missions, a nine-step practice flow, typed and microphone answers, self-checks, progress maps, profile, and mission completion.
