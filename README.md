# Omalingo

A mobile-first interactive prototype based on the Omalingo Figma learning flow.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://127.0.0.1:5173`.

## Production build

```bash
pnpm build
pnpm preview
```

The prototype includes the complete 20-step Mission 11 flow: scene playback, answer states, listening practice, microphone recording, typed answers, self-checks, a mission map, and the completion screen.
